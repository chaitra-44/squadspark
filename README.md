# 🚀 ABTalks — Build in Public. Win in 60 Days

> ⚡ A gamified platform that turns students into consistent builders using daily challenges, streaks, and public accountability.
---

## 🧠 The Big Idea

Most students don’t fail because they lack skill.  
They fail because they lack **consistency + visibility**.

**ABTalks** solves this by combining:
- 📅 Daily coding missions  
- 🔥 Streak-based motivation  
- 🌍 Public sharing (GitHub + LinkedIn)  
- 🧩 Portfolio-first learning  

👉 Result: Students build **real projects**, not just watch tutorials.

---

## 🎯 Problem → Insight → Solution

### ❌ Problem
- Tutorial hell is real  
- No structure → no consistency  
- No public proof of work  
- Low recruiter visibility  

### 💡 Insight
> People stay consistent when progress is visible and rewarded.

### ✅ Solution
A **Duolingo-style coding system** for developers:
- Daily tasks  
- Streak tracking  
- Public submissions  
- Reward loops
