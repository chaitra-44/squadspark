#Dashboard page(/Dashboard):

Design a mobile-first dashboard screen (390px width) for a 60-day coding challenge app.

The user is a college student building daily projects and maintaining a streak.

The UI should be dark-themed, modern, minimal, and highly motivating.

Include the following sections:

1. Header:
- Greeting like "Hey, keep building 🚀"
- Small profile avatar

2. Current Streak Card (very prominent):
- Show streak like "🔥 Day 5"
- If no streak: show "Start your streak today"
- Use strong visual emphasis

3. Today's Task Card:
- Task title (e.g., "Build a Landing Page")
- Short description
- Primary CTA button: "View Task"

4. Progress Section:
- Show progress like "12 / 60 days"
- Include a progress bar

5. Achievements / Standing:
- Example badges like "Consistency Badge"
- Rank like "Top 20%"

6. State Handling:
- Empty state (no activity yet)
- Missed day warning
- Completed today state (show checkmark)

Design requirements:
- Mobile-first (390px)
- Clean spacing, soft shadows, rounded cards
- Smooth hierarchy and readability at night (low brightness usage)
- Focus on habit-building and motivation (Duolingo-like feel)

Do NOT include:
- Authentication
- Complex navigation
- Desktop layout

Output should look like a real production-ready app UI.

#ChallengeDay(/day/12):

Design a mobile-first "Challenge Day" screen (390px width) for a coding challenge app.

This screen represents a single day (e.g., Day 12 of 60).

The goal is to help the user understand the task and submit proof of work.

UI should be dark-themed, minimal, and focused.

Include:

1. Header:
- Back button
- Title: "Day 12"

2. Task Section:
- Task title (e.g., "Build a Landing Page")
- Clear description
- "What to build" section with bullet points

3. Submission Section:
- Input field for GitHub repository or commit link
- Input field for LinkedIn post link
- Primary CTA button: "Submit Proof"

4. Feedback States:
- Success state (submission complete ✅)
- Error/empty state (missing links)
- Loading state

5. Motivation Element:
- Small message like "Keep your streak alive 🔥"

Design requirements:
- Mobile-first (390px)
- Clean card layout
- Strong CTA button
- Simple form UX (easy to use at night)

Do NOT include:
- Backend logic
- Authentication
- Complex features

Focus on clarity and quick submission experience.
